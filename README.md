# Shaktitec Global Website

Static responsive website for Shaktitec Global.

## Deploy to Render

This is a static site. You can deploy it directly from GitHub.

Recommended Render settings:

- **Build Command:** leave blank
- **Publish Directory:** `.`
- **Environment:** Static Site

No Node.js or build process is required.

## Before going live

1. Replace the contact form behavior in `script.js` with your preferred form/email service.
2. Add your final company email address.
3. Add your social/profile links if required.
4. Add a favicon and company logo if you have finalized them.
5. Review the legal/privacy pages required for your business.

## Local preview

Open `index.html` in a browser.
